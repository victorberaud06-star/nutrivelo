# NutriVelo Pro 3

Version gratuite, locale et installable. Nouveautés : plusieurs entraînements par jour, journal des écarts sans culpabilisation, estimation locale des glucides/protéines/lipides/calories à partir de descriptions de repas.

## Mise à jour GitHub Pages
Décompresser puis remplacer les fichiers du dépôt par ceux de cette archive. Conserver `index.html`, `manifest.json`, `sw.js` et les deux icônes à la racine. Attendre 1 à 3 minutes puis forcer l’actualisation.

## Important
L’estimation nutritionnelle repose sur un dictionnaire local d’aliments courants. Elle n’est ni une base nutritionnelle exhaustive ni un avis médical. Indiquer les quantités en grammes améliore la précision.

# NutriVelo Pro

Application PWA gratuite de suivi nutritionnel cycliste. Aucune dépendance, aucun compte, aucune publicité. Les données sont enregistrées localement dans le navigateur.

## Test local

Dans ce dossier : `python3 -m http.server 8000`, puis ouvrir `http://localhost:8000`. Un simple double-clic sur index.html permet de tester l'interface, mais l'installation et le mode hors ligne nécessitent localhost ou HTTPS.

## Mise en ligne gratuite avec GitHub Pages

1. Créer un dépôt public GitHub.
2. Déposer tous les fichiers à la racine.
3. Settings > Pages > Deploy from a branch > main / root.
4. Ouvrir l'adresse fournie par GitHub.
5. Sur mobile, utiliser « Ajouter à l'écran d'accueil ».

## Confidentialité

Les données restent sur l'appareil. Utiliser Exporter JSON pour une sauvegarde. Effacer les données du navigateur supprimera les saisies locales.
